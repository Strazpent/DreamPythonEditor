1Ctrl+Space and the runtime type. The header says what sel[0] is right now, a StaticMeshActor, while static analysis only knows Actor. The resolver follows names and literal indexes, calls nothing, and took 1.8 ms of its 5 ms budget.
2Merged, ranked sources. Every item has a source badge: runtime, static, keyword or snippet. In the REPL, runtime members rank first. A name both sources know appears once, with the static signature. Snippets come last.
3Signature help. It opens on ( and highlights the parameter being typed, here name. It sits above the line so the completion list can open below.
4Editor-property names. Inside set_editor_property('…') and get_editor_property('…') the list holds the class's editor properties with their types. Names come from the class's Editor Properties docstring list; no getter is called.
5Quick docs. Ctrl+Q shows the card for the symbol at the caret; resting the mouse shows the same card. It holds the signature, the docstring generated from C++, the methods and the owning module and plugin.
6Pin, reference, stub. Ctrl+Q again pins the card. ↗ opens the online Python API page; F12 opens the read-only stub. F1 stays with Unreal.
7Quick fix, Ctrl+. SUM102 rewrites obj.prop = v as obj.set_editor_property("prop", v). The light bulb marks the line. The PyCharm preset uses Alt+Enter.
8SUM lint codes. dream-check runs out of process. SUM1xx is the Unreal API (SUM101 unknown name; SUM102 by default only where an attribute write cannot work, such as an editor-only property, which raises AttributeError, or a read-only one; SUM103 deprecated; SUM104 actor edits in a loop without a transaction, only when One undo step per run is off), SUM2xx threads and the game thread, SUM3xx files. An off-by-default SUM102 variant also flags writes that skip edit-change notifications.
9Problems. Problems from all open files, grouped by file, with rule code and source. F8 and Shift+F8 walk them. A run's uncaught exception also appears here as a runtime item.
10Language service health. The language server, ruff, dream-check, the stubs and runtime completion each show their state. After repeated crashes this reads “Language features paused — Restart / View log”; typing and running are never blocked.
