1Where settings live. Editor Preferences › Plugins › Dream Python Editor, split into pages. Search filters every page at once, including commands and chords. Settings are non-modal like the rest of Dream.
2Precedence. A policy lock wins: machine policy (%ProgramData%\DreamPythonEditor\Policy.json, used only if it is admin-owned), then studio policy (DREAM_POLICY_PATH), then project policy (<Project>/Config/Dream/Policy.json). Otherwise your value (global or this project) wins, then the project default, then the built-in default.
3Effective-value inspector. “Why this value?” lists every layer, its file and its value for this key, and marks the one that won. Here the machine policy forces the Run window, so your Live (docked) Preview choice is ignored.
4Locked by policy. A padlock, the layer and the key. The debugpy socket is a documented, user-started exception to “every listener is authenticated”, and a policy key can forbid it, as here.
5Keymap presets. Charcoal is the default; PyCharm and VS Code presets switch the chords in one step. The keymap is a global user setting, so it follows you across projects.
6The Charcoal keymap. Stop is Esc (unless a script's own dialog is open) and Shift+F5, never Ctrl+Break. F5 debugs and continues, Ctrl+F5 runs the entry point, Ctrl+Space is the only completion chord, F4 walks error links, F8 walks Problems and Ctrl+M toggles whether Tab moves focus. Alt+Enter runs the line under the caret and moves to the next statement; the PyCharm preset leaves it unbound, because Alt+Enter is Quick fix there. No Unreal command binds Alt+Enter, so the Shadowed page lists nothing for it.
7The trust prompt is an inline banner. Run is disabled for files outside trusted folders; the file still opens and edits. Trust this folder is remembered per user; Run once is not, and is audited. Default focus is on neither button.
8Not executed. The trust check is the first step of Starting. A refused run still gets a number and the outcome not executed, and the status-bar item says so.
9Trusted folders. Built-in roots (the project, the Dream libraries, UE AdditionalPaths), studio roots from policy, and the folders you trusted, which you can remove here.
10Shadowed Unreal shortcuts, stated plainly: each chord Dream takes while focused, the Unreal command it hides, and the preset that adds it, computed from the main-frame bindings, the Level Editor command list and the consume list. Ctrl+Tab, F1 and Alt+F1 are never taken.
11Output position. layout.output_position: Top, the default, puts the output area above the code as in Maya's Script Editor; Bottom is the PyCharm arrangement. A user setting with no policy key; View ▸ Output Position and the palette commands Move Output to Top / Bottom move it at once and keep its size.
