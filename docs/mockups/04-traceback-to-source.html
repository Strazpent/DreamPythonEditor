1Red run block. A failed run gets a red header and a red edge down its lines: run number, the buffer and lines that ran, time, duration, the outcome error and the undo step Dream: Untitled-3 #31. Errors keep their transaction; Undo this run reverts it. Below, the buffer's gutter marks Run #31 statement by statement (EDT-18): lines 12–16 ran ok, the for statement (lines 17–19) raised, and line 20 was never reached.
2Typed lines. Echo, output, info, warnings and errors each have their own colour and a show/hide toggle. Here Echo (the toolbar's Echo input) is switched off, so only what the run printed or logged is shown, not the statements it ran.
3Frames name the buffer. An untitled buffer has no __file__, so its frames use the pseudo-filename <dream:Untitled-3#a41f>, registered in linecache; a41f is the first 4 hex digits of the buffer's id, extended until it is unique. Line 18 is the real buffer line, not line 7 of the selection.
4Clickable frames, and F4. Every frame and error link is clickable. F4 and Shift+F4 walk the frames and error links in the output; hovering shows where a link goes.
5Where you came from. A slim bar says the tab was opened from Run #31's traceback and which frame this is. Back to Output returns to the run block. Breadcrumbs show the path and the function.
6The error stays on the line. The raising line is tinted red, the failing expression is underlined, as the 3.11 carets mark it, and an inline note repeats KeyError: 'LOD1'.
