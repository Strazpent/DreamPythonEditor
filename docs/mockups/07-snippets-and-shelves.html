1Shelves. Rows of buttons bound to library items, with icon and tooltip. The tabs switch between the studio (locked), project and user shelves. A shelf is a data file in the library, here Dream/Library/shelves/citysample.shelf.json; it can also appear in the Level Editor toolbar and the Tools menu.
2Drag a selection onto the shelf. Dropping selected code on the shelf (the Maya middle-drag habit) shows where the button will land, then opens Save as snippet (A), so every button is backed by a real library item.
3Four tiers. Built-in (read-only, ships with Dream), User (the user settings folder), Project (<Project>/Dream/Library/, under source control, outside Content so it is never cooked) and Studio (a path from policy, pinned by a SHA-256 manifest).
4${param:name} placeholders. Declared in the item's params block and filled from the form when the item runs. Values are substituted as repr literals, never pasted raw. Insert shows no form: each parameter becomes a tab stop holding its default literal. The rest is VS Code snippet syntax, so existing collections import as they are.
5Shelf runs in Output. Each shelf run is numbered and shows the item, its tier and version, the Isolated namespace and the values entered. A real run is one transaction, Dream: Batch Rename #42; because it renamed assets, Dream clears the undo history when it ends, and the block says so (RUN-07).
6Save as snippet is non-modal: you can keep editing, or select more code, while it is open. Name, category and Tab prefix; one item per file.
7Parameters. Types are string, int, float, bool, enum, asset_path, and the selection types actors and assets, whose default "$selection" takes the current selection. A literal such as "_N" can be promoted in one click.
8Publish to library. Writes the item file into the chosen tier folder and checks it out through source control. For the studio tier it also writes the manifest entry, or, without write access, produces the change for the library owner.
9The parameter form. Non-modal, asked once per run of the item. It remembers your last values per item, and an assets field shows the selection count with Pick again.
10The Dream Shelf tab. A standalone dock tab with the same shelf bar and no editor, for artists who never open the Dream tab. The result goes to the Dream output and to the Unreal status bar item. A run that ends error, cancelled or not executed also shows an editor notification with the item name, the outcome and the exception's last line, plus Details and Undo this run (not for a run that renamed assets). Undo on this tab is Undo Last Run, and Ctrl+Alt+Z works while the tab has focus.
11Modified since publish. The item no longer matches its pinned hash, so the library and shelf show ⚠ and running asks first, in a non-modal prompt with no default action (U39, RV-09): no button has focus, Enter does nothing, and the three buttons carry equal weight. Running the changed copy is an explicit, audited, one-time choice. If a policy sets library.studio.require_pinned, the item cannot run and the prompt offers only Restore.
