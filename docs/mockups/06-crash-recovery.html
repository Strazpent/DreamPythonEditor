1Recovery banner. After an unclean exit the tab reopens with a non-modal banner. The count is the number of buffers whose journal holds changes that are not on disk; another instance's buffers are not counted and are listed apart. Restore all, Review and Discard; you can keep working while you decide. Until you choose, each pending tab (⟲) is read-only under “Not restored yet”.
2Discard is not delete. Discard moves the journals into local history, so a wrong click can be undone from the timeline.
3The conflict rule. If the disk file changed after the journal's base version, the recovered buffer opens as batch_rename.py (recovered) next to the disk version, and nothing is overwritten.
4Recovered versus disk. Blue marks text only in the recovered copy, green text only on disk. Once restored, copy hunks across, or use Save over batch_rename.py…, which asks before it overwrites the disk file.
5Review is a docked panel. It is not modal: the editor and the other tabs stay usable. Each buffer shows its state and when it was last journaled. Another editor instance's buffers are listed separately and unticked.
6Runs cut off by the crash. A run that was active when the editor exited is recorded with the outcome lost, in the output and the audit log.
7Where journals live. %LOCALAPPDATA%\DreamPythonEditor\5.8\CitySample-7c41e2\: engine version, then the project name plus the first 6 hex digits of a SHA-256 of the .uproject path. Never in the project or the engine tree.
8Safe mode. Entered automatically after two crashes in a row during session restore, or with -DreamSafeMode, or Shift while opening the tab. It skips session restore but still lists what can be recovered.
9Timeline of snapshots. Local history records every save, every run (just before it starts), every external reload and recovery events. Identical snapshots are stored once. The default budget is 30 days and 500 MB per project.
10External reloads are kept. When a P4 sync replaced a clean buffer, the text from before the sync stayed in the timeline.
11Side-by-side diff. The selected snapshot (left, read-only) against the current buffer (right), with changes highlighted inside each line. Tick hunks in the middle column to take back only those parts.
12Restore actions. Restore replaces the buffer text as one undoable edit. Restore as new tab opens the snapshot beside your text. Revert selected hunks applies only the ticked hunks. Nothing reaches disk until you save.
