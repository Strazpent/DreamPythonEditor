1The Paused window. One modal window holds the whole 1.0 debugger: call stack, variables, watches, an evaluate console and a read-only source view. It opens at the pause, remembers its size and position, and is parented to a user's open slow-task dialog when there is one. It never uses the engine's debugging mode, so unreal.* calls in watches return real values.
2Stepping keys. Continue F5, Step over F10, Step into F11, Step out Shift+F11, Stop Shift+F5. Run to cursor is Ctrl+F10 with the caret in the source view. Stop raises ScriptCancelled, so the run ends as cancelled with no rollback. Esc stops when focus is not in a text field; in the evaluate console or a watch edit, Esc first closes completion, then clears or cancels the input.
3Read-only source. The paused line has a yellow arrow and tint; the gutter shows a conditional breakpoint (27), a disabled one (22), a logpoint (28) and a plain breakpoint (34). F9 toggles a breakpoint here, and Shift+F9 or right-click a glyph edits a condition here; the tab's gutter is unreachable while paused.
4Call stack. Frames run from the cell into studio_tools/naming.py and back. Clicking a frame shows its source and switches Variables, Watch and Evaluate to it. Dream's own runner frames are hidden.
5Lazy, UObject-aware variables. Nothing is read until you expand it. Unreal properties are read with get_editor_property on expand, never through attribute getters, and containers page 100 items at a time.
6Safe watches refresh automatically while paused and after each run. They may use names, attribute reads through the safe resolver, literal subscripts and a short list of built-ins such as len, type and isinstance.
7Manual watches. Any other expression, such as a method call, is marked “may run code” and is evaluated only when you click ⟳. The time of the last evaluation is shown.
8Evaluate. Runs any expression or statement in the selected frame on the game thread. It can modify editor state, and those edits land in the run's transaction and share its fate: Run #14 renames assets, so its undo history is cleared when it ends (RUN-07).
9Pause rules. The footer says the REPL is suspended. Pauses happen only in Dream debug runs, on the game thread. A breakpoint inside a Python Slate or ticker callback is skipped with a notice and the callback continues. Editor close and PIE start are refused while paused.
10The editor behind. While this modal is open only the modal, tooltips and notifications are drawn, and input to every other window is ignored. The editor keeps the frame it painted before the run, undimmed, with the output area above the code as by default: WS-07 still reads Dream · Starting · Run #14 and shows no Paused state (screen readers and the API still get it). Docked debug panels are Later.
